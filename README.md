# SAHIL | Developer Portfolio

A personal developer portfolio built with React, TypeScript, Tailwind CSS, and shadcn/ui.

## Getting Started

### Installation

```sh
npm install
```

### Development

```sh
npm run dev
```

### Build

```sh
npm run build
```

## Features

- Responsive design
- Animated transitions
- Project showcase
- Skills section
- Contact form

## Technologies Used

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Framer Motion
